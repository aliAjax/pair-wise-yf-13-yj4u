# hxyfront-62001 船舶轮机值班记录

面向船舶轮机值班的前端记录系统：轮机员按班次录入主机转速、滑油压力、冷却水温、
燃油消耗、舱底水状态和巡检项，系统按**每台设备各自的安全范围**实时判定，
开出异常单并生成交接班摘要。所有数据仅保存在浏览器本地（localStorage）。

## 业务规则

- **按设备的安全范围**：轮机长（右上角切换“轮机长”角色）可在“安全范围设置”中
  按设备调整主机转速、滑油压力、冷却水温的上下限。不同设备可有不同范围，
  不监测某项的设备不显示该项。
- **判定快照不可追溯修改**：每条读数保存时写入“按当时范围得出的判定”
  （正常/越限、严重度、当时上下限）。事后修改阈值，只影响新读数，
  已保存班次里的读数判定、异常单和交接摘要均保持原样。
- **异常持续到人工处理**：数值越限即开出异常单；后续读数即使恢复到范围内，
  异常单仍以“已恢复·待处理”留在时间线，不会自动关闭。
  同设备同参数的后续越限读数并入同一张单。关闭必须填写**处理人**和**处理结果**，
  归档后仍保留在时间线可查。
- **交接班摘要冻结**：交班瞬间按设备列出“最严重的一条未完成异常”
  （危急 > 严重 > 一般，同级取最早），随班次冻结保存；
  交班同时自动开新班，之后任何变化都不修改该快照。
- **严重度**：越限幅度超过该参数安全范围宽度 20% 记为“危急”，其余越限记“严重”；
  文本类巡检项可由轮机员手动标记一般/严重/危急。
- **数据本地化**：班次、读数、异常单、摘要及角色/署名偏好均存于浏览器 localStorage，
  不上传任何服务器；页首提供“重置本地数据”。

## 页面结构

- 班次栏：切换查看各值班班次；已交班班次为只读
- 交接班摘要：未交班显示实时预览，交班后显示冻结快照
- 机舱参数看板：按设备展示各参数最新读数与异常状态（含“已恢复·待处理”）
- 按设备筛选：联动看板、时间线
- 读数录入：选择设备/参数后显示当前安全范围与判定预览，保存即写快照
- 异常时间线：异常单与读数混排，可登记处理人与处理结果
- 安全范围设置：仅轮机长可改
