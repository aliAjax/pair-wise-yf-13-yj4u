# hxyfront-62001 船舶轮机值班记录

面向船舶轮机值班的前端记录系统，轮机员可以记录主机转速、滑油压力、冷却水温、燃油消耗、舱底水状态和巡检异常。包含值班班次切换、机舱参数看板、异常记录时间线、交接班摘要和按设备/班次筛选的历史记录。所有数据保存在浏览器本地（localStorage）。

## 安全范围（阈值）规则

- **按设备配置**：轮机长可在值班台为每台设备分别设置主机转速、滑油压力、冷却水温的安全范围（下限/上限），轮机员只读；每次调整写入修订记录（调整人、时间、说明）。
- **录入当时判定**：读数保存时按**当时**的安全范围判定为正常 / 警告越限 / 严重越限，并把所用范围与判定结果作为快照存入该条读数。
- **阈值后改不回改历史**：之后调整范围只影响新录入；已保存班次里每条读数的判定、异常描述和交班摘要都不会改变。
- 紧急裕度：超出限值且超出量大于安全区间宽度的 10% 判为“严重”，否则为“警告”。

## 异常规则

- 参数越限自动生成异常，异常内嵌当时的范围快照。
- **读数恢复正常不会自动关闭异常**；同设备同参数再次越限会并入同一条异常并累计触发记录。
- 舱底水“接近警戒线”为预警（不生成异常），“高位报警”生成严重异常。
- 异常必须填写**处理人**和**处理结果**才能标记完成；已处理异常仍保留在时间线。异常可跨班次处理，处理记录登记到当前进行中的班次。

## 交接班摘要

- 交班确认时生成并冻结摘要：按设备列出最严重的一条未完成异常（严重 > 警告），含发生班次、当时范围、累计触发次数、交接备注。
- 摘要冻结后，异常再被处理或阈值再调整，摘要内容均不变化。
- 进行中的班次可查看实时预览（未冻结）。

## 技术栈

React 19 + Vite + TypeScript，数据仅存浏览器 `localStorage`（键名 `hxyfront-62001-watch-state-v1`）。

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62001

## 验证

```bash
npx tsc --noEmit          # 类型检查
npm run build             # 生产构建

# 领域规则（42 项）与界面冒烟（23 项），需 esbuild（vite 自带）与 jsdom：
node_modules/.bin/esbuild verify/check.ts --bundle --platform=node --format=esm --outfile=.tmp/check.mjs --external:jsdom --log-level=warning && node .tmp/check.mjs
node_modules/.bin/esbuild verify/smoke.tsx --bundle --platform=node --format=esm --outfile=.tmp/smoke.mjs --external:jsdom --log-level=warning && node .tmp/smoke.mjs
```

页面顶部可一键“重置为演示数据”或“清空本地数据”。演示数据含昨日两个已交班班次（冻结摘要）、今早已调整的主机/发电机阈值，以及进行中的 08-12 班，便于直接验证“阈值后改不回改历史判定”。
